# Digital Design Notes
A collection of notes and codes meant for **studying digital design and verification**. Some of the modules might be used in the future.

# Tools used

I know that the "big three" available tools are cadence xcelium, siemens questasim and synopsis vcs. But as much as possible I want to constraint tool usage to open-source toolings. The tools used in this repositories is constrained to:

1. verilator (verification)
2. yosys (synthesis)
3. symbiyosis (formal verifcation)
4. nextpnr (place and route)

# Thorough comments
Note that since this is a repo meant for study, expect the RTL and testbench codes to be very thoroughly commented. You will also notice that codes will contain highly thorough comments that is sometimes redundant with the markdown notes.
