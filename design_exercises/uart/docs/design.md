# UART Protocol

[!Reference]
Analog Devices has a [good article that explains uart protocol](https://www.analog.com/en/resources/analog-dialogue/articles/uart-a-hardware-communication-protocol.html).

# Packet Format

| Start bit (1-bit) | Data Frame (5-9 bits) | Parity Bits (0-1 bit) | Stop Bits (1-2 bits) |
|-|-|-|-|

1. The **start bit** indicates the start of packet transmission. The **tx line** is pulled low for 1 clock cycle which will indicate to the receiving end the start of data transmission.

# Requirements

## Base Requirements
1. UART oversampling at 16x.
1. Tx must drive the start bit for 1 clock cycle (16 oversampling ticks) to indicate start of transmission.
3. Data Frame will be fixed to 8 bits.
4. Must be able to enable or disable parity bits.
5. Must be able to set parity to odd or even parity.
6. Must be able to configure the stop bits to 1 or 2 bits.
7. Baudrate must be configurable

## Miscellaneous
1. detect line idle time
2. raise interrupt for rx fifo watermark detection
3. raise interrupt for tx fifo watermark detection

## Error detection
Note that all error detection must reflect in STATUS bits and must be raised as an interrupt if interrupt mask for this error detection bits is enabled.

1. Must detect **parity error** if PARITY_EN=1.
2. Must detect rx fifo **overflow**.
3. Must detect **framing error** (cause by line noise or baudrate mismatch).
4. Must detect **break** condition (when rx line is hold longer than full frame).

# UART Transmitter Signal List


| Signal Name | Direction | Width | Driver | Description |
|-------|:-------:|:---:|-----|-------------------------|
|clk_i | i | 1 | tbd |  main clock, also used for sampling |
|rst_i | i | 8 | tbd |  active low reset signal |
|data_i | i | 8 | tbd |  Data to be transmitted |
|start_i | i | 1 | fifo |  Signals the start of transmission |
|parity_en_i | i | 1 | tbd |  Parity enable |
|parity_i | i | 1 | tbd |  Set initial parity, =1 at even, =0 at odd |
|num_stop_bit_i | i | 1 | tbd |  number of stop bits, zero-based count|
|baud_tick_i | i | 1 | tbd | single cycle tick generated by clk div generator |
|tx_o | o | 1 | tbd |  Transmit signal output |
|busy_o | o | 1 | tbd |  indicates active transmission |
|done_o | o | 1 | tbd |  tick that indicates transmission done |


# State Machine

States:
1. UART_TX_IDLE
2. UART_TX_START
3. UART_TX_DATA
4. UART_TX_PARITY
5. UART_TX_STOP
6. UART_TX_DONE

```Mermaid
stateDiagram-v2
    Reset --> UART_TX_IDLE
    UART_TX_IDLE --> Reset : rst_i=1
    UART_TX_IDLE --> UART_TX_START : start_i=1
    UART_TX_START --> UART_TX_START : ticks<16
    UART_TX_START --> UART_TX_DATA : ticks==16
    UART_TX_DATA --> UART_TX_DATA : shift<8
    UART_TX_DATA --> UART_TX_PARITY : parity_i==1 && shift==8
    UART_TX_PARITY --> UART_TX_STOP : ticks==16
    UART_TX_DATA --> UART_TX_STOP : parity_i==0 && shift==8
    UART_TX_STOP --> UART_TX_DONE : ticks==(16 << num_stop_bit_i)
```
