# SystemVerilog for RTL Design
Not all features of systemverilog is used for RTL design. There is no standard in systemverilog for RTL. It is up to the tool developer to indicate what features of systemverilog the RTL synthesis tool supports.

# ASIC Design Flow
ASIC design flow is split into two:

## Front End
> **Design Specification**
> **RTL Modeling**
> **Cycle-based Functional Simulation and Verification**
> **RTL Synthesis**
> **Functional Equivalence Verification**

## Back End
> **Scan chain and clock tree insertion**
> **Place and Route (PNR)**
> **Design Rule Checking (DRC)**
> **Static Timing Analysis (STA)**
> **GDSII Tape Out**
